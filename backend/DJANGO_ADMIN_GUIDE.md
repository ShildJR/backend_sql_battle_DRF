# 🎛️ Django Admin — Массовое назначение задач

## Быстрый старт

### 1. Создайте суперпользователя (если ещё не создан)

```bash
cd backend
python manage.py create_admin --username admin --password admin123
```

### 2. Запустите сервер

```bash
daphne -b 0.0.0.0 -p 8000 sql_battle.asgi:application
```

### 3. Откройте Django Admin

Перейдите по адресу: **http://localhost:8000/admin/**

Войдите с учётными данными администратора.

---

## 📋 Массовое назначение задач

### Способ 1: Через Task Assignments

1. Перейдите в раздел **Task assignments**
2. Нажмите кнопку **"Массовое назначение задач"** вверху страницы
3. Заполните форму:
   - **Тип назначения**: выберите "Пользователю" или "Группе пользователей"
   - **Пользователи/Группа**: выберите одного или нескольких пользователей (или группу)
   - **Задачи**: выберите одну или несколько задач
4. Нажмите **"Назначить задачи"**

**Пример:**
- Выбрано 5 пользователей
- Выбрано 3 задачи
- Результат: 15 назначений (5 × 3)

### Способ 2: Через User Groups

1. Перейдите в раздел **User groups**
2. Создайте новую группу или выберите существующую
3. Нажмите **"Назначить задачи"** рядом с группой
4. Выберите задачи для назначения
5. Нажмите **"Назначить задачи"**

**Пример:**
- Группа "Команда А" с 10 пользователями
- Выбрано 5 задач
- Результат: 50 назначений (10 × 5)

## 👥 Управление группами

### Создание группы

1. Перейдите в **User groups**
2. Нажмите **"Добавить User group"**
3. Заполните форму:
   - **Название группы**: например, "Команда А"
   - **Описание**: опционально
   - **Пользователи**: выберите участников группы
4. Нажмите **"Сохранить"**

### Редактирование группы

1. Перейдите в **User groups**
2. Нажмите **"Изменить"** рядом с группой
3. Измените название, описание или участников
4. Нажмите **"Сохранить изменения"**

### Назначение задач группе

1. Перейдите в **User groups**
2. Нажмите **"Назначить задачи"** рядом с группой
3. Выберите задачи для назначения
4. Нажмите **"Назначить задачи"**

---

## 📊 Просмотр назначений

В разделе **Task assignments** можно:

- **Фильтровать** по пользователю или задаче
- **Видеть статус** назначения:
  - `assigned_at` — когда назначена
  - `started_at` — когда начата
  - `completed_at` — когда завершена
- **Удалять** отдельные назначения

---

## 🔧 API Endpoints для массового назначения

Помимо Django Admin, можно использовать API:

### Назначение задач пользователю

```bash
POST /admin/users/{user_id}/assign
{
  "task_ids": [1, 2, 3]
}
```

### Назначение задач группе

```bash
POST /admin/groups/{group_id}/assign
{
  "task_ids": [1, 2, 3]
}
```

### Создание группы

```bash
POST /admin/groups/create
{
  "name": "Команда А",
  "description": "Первая команда",
  "user_ids": [1, 2, 3, 4, 5]
}
```

## 💡 Советы

1. **Используйте группы** для быстрого назначения задач нескольким пользователям
2. **Проверяйте назначения** в разделе Task assignments перед началом баттла
3. **Массовое назначение** экономит время при подготовке к мероприятию
4. **Фильтры** в Django Admin помогают быстро найти нужные назначения

## 🐛 Решение проблем

### Ошибка "Группа не найдена"
- Убедитесь, что группа создана и имеет хотя бы одного участника

### Задачи не назначаются
- Проверьте, что задачи существуют и активны
- Убедитесь, что пользователи не имеют дублирующихся назначений

### Не видна кнопка "Массовое назначение задач"
- Убедитесь, что вы вошли как суперпользователь
- Проверьте права доступа в Django Admin
