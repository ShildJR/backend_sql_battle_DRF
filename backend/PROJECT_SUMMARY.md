- ✅ CORS настройки
- ✅ JWT токены с ограниченным временем жизни

## 🚀 Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Миграции
python manage.py makemigrations
python manage.py migrate

# 3. Создание администратора
python manage.py create_admin

# 4. Загрузка тестовых задач (опционально)
python manage.py loaddata api/fixtures/tasks.json

# 5. Запуск сервера
python manage.py runserver
```

## 🎯 Особенности реализации

### 1. Массовое назначение задач
- Назначение задач одному пользователю
- Назначение задач группе пользователей
- Автоматическая установка дат (start + 1 мин, end + 24 часа)

### 2. Безопасный SQL sandbox
- Выполнение только SELECT запросов
- Защита от опасных операций (DROP, DELETE, UPDATE)
- Ограничение по времени выполнения
- Изолированная среда для каждого запроса

### 3. WebSocket лидерборд
- Обновления в реальном времени
- Аутентификация через query-параметр
- Автоматическое переподключение

### 4. Гибкая система настроек
- Настройки в базе данных (модель BattleSettings)
- Публичный и админский доступ
- Динамическое обновление
